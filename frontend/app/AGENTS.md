# Task Tracking UI design requirements

Apply these requirements to every new or modified UI component, page, dashboard, form, table, modal, sidebar, and navigation element in this project.

## Approved palette

- Primary: `#2A317A` for buttons, active states, links, icons, highlights, and primary UI elements.
- White: `#FFFFFF` for page, card, form, and other surface backgrounds.
- Charcoal gray: `#3C3C3B` for secondary text, icons, borders, and subtle details.
- Black: `#000000` for text and small details only; never use it as a background.
- Light and dark tints of these approved colors are allowed for hierarchy.
- Gradients may use the primary palette selectively, for example `linear-gradient(135deg, #2A317A, #414A9B, #2A317A)`.

## Requirements

- Keep the interface clean, modern, professional, and light, with white or very light backgrounds.
- Maintain readable text and good contrast.
- Never use green or introduce unrelated colors.
- Never use black, near-black, dark navy, or dark charcoal as a background.
- Apply the palette consistently across all pages and components.
- Reuse existing project styling conventions and CSS variables when available.
- Preserve existing functionality and layout unless the user explicitly requests a change.
